# AI 문제 생성 프롬프트

`풀이장` 앱이 읽는 Google Sheet 양식(`docs/superpowers/specs/2026-09-03-sheet-quiz-architecture-design.md`
§8.1)에 맞춰 AI가 바로 문제를 생성하도록 만든 프롬프트. ChatGPT/Claude 등
아무 AI 챗봇에나 붙여넣고 `{자격증명}` 등 변수만 채워서 사용한다.

## 사용법

1. 아래 프롬프트 전체를 복사한다.
2. `{자격증명}`, `{문제_개수}`, `{시작_번호}`를 실제 값으로 바꾼다.
3. AI 응답으로 나온 표(TSV)를 그대로 드래그해서 복사한다.
4. Google Sheets에서 빈 시트의 A1 셀을 클릭하고 붙여넣는다 — 탭으로
   구분되어 있으므로 열이 자동으로 나뉜다.
5. 앱에서 불러와 검증 화면에 오류/경고가 없는지 확인한다.

같은 시트에 문제를 이어서 추가할 때는 `{시작_번호}`를 마지막으로 쓴 번호
다음 값으로 바꿔서 다시 실행한다 (앱이 `번호` 중복을 오류로 처리하기
때문).

## 프롬프트

```
너는 국가/민간 자격증 시험 문제 출제 전문가다. 아래 조건에 정확히 맞는
객관식 문제를 생성하라.

[생성 대상]
- 자격증명: {자격증명}
- 문제 개수: {문제_개수}
- 시작 번호: {시작_번호} (이 번호부터 1씩 증가, 절대 중복 금지)

[내용 요구사항]
- 실제 시험 범위/최신 출제 경향에 부합하는 내용만 사용한다. 근거 없는
  내용, 지어낸 법조항/수치는 절대 넣지 않는다. 확신이 없는 지식이면 그
  문제는 생성하지 말고 더 확실한 주제로 대체한다.
- 문제마다 "분류"(자격증 시험의 과목/영역 구분)를 채운다. 여러 과목이
  고르게 섞이도록 분배한다.
- 난이도는 EASY : MEDIUM : HARD ≈ 3 : 5 : 2 비율로 섞는다.
- 유형은 단일 정답(SINGLE)을 기본으로 하되, 전체의 20~30%는 복수 정답
  (MULTIPLE, 정답 2개 이상)으로 만든다.
- 선택지는 기본 4개(A~D), 필요하면 최대 6개(A~F)까지 쓸 수 있다.
  오답도 그럴듯하게 만들어서 단순 소거로 풀리지 않게 한다.
- 문제 해설(explanation)에는 정답의 근거를 구체적으로 쓴다. 가능하면
  각 보기별 해설(보기 A 해설 등)도 채워서 오답이 왜 틀렸는지 설명한다.
- 문제 본문/보기/해설 텍스트 안에 줄바꿈을 넣지 않는다(한 문단으로).

[출력 형식 — 반드시 지킬 것]
- 아래 열 순서 그대로, 탭(TAB) 문자로 구분된 표 형식(TSV)으로만
  출력한다. 표 앞뒤로 설명 문장, 코드블록 언어 표시, 마크다운 굵게 등
  다른 텍스트를 절대 추가하지 않는다.
- 첫 줄은 반드시 아래 헤더 그대로:
  번호	분류	난이도	유형	문제	보기 A	보기 B	보기 C	보기 D	보기 E	보기 F	정답	해설	보기 A 해설	보기 B 해설	보기 C 해설	보기 D 해설	보기 E 해설	보기 F 해설	핵심 키워드	관련 주제
- 보기 E/F를 쓰지 않는 문제는 해당 셀을 빈 문자열로 둔다(중간에 있는
  보기 A~D는 절대 비우지 않는다 — 선택지는 A부터 빈칸 없이 연속으로
  채워야 함).
- "정답" 열은 선택지 문자를 쉼표로 구분해서 쓴다. 예: 단일 정답이면
  `C`, 복수 정답이면 `A,C`. 정답은 실제로 존재하는 보기 문자만 쓰고,
  같은 문자를 중복해서 쓰지 않는다.
- "난이도"는 `EASY`/`MEDIUM`/`HARD` 중 하나만 쓴다.
- "유형"은 `SINGLE`/`MULTIPLE` 중 하나만 쓴다. SINGLE이면 정답은
  정확히 1개, MULTIPLE이면 정답은 2개 이상이어야 한다.
- "핵심 키워드", "관련 주제"는 쉼표로 구분한 짧은 단어/구 목록(선택,
  비워도 됨).
- "상태", "정답 개수", "세트 ID", "출제일", "상황", "참고 URL" 열은
  이 프롬프트에서 사용하지 않으므로 출력에 포함하지 않는다.

지금 바로 {시작_번호}번부터 {문제_개수}개를 생성해서 위 형식의 TSV
표만 출력하라.
```

## 참고

- 정답 근거는 AI가 최신 개정 법령/기준을 반영하지 못할 수 있으므로,
  실제 시험에 쓰기 전에는 최소 표본을 사람이 검수하는 것을 권장한다.
- 시트에 이미 있는 문제와 "번호"가 겹치면 앱이 해당 행을 오류로
  표시한다 — 이어서 생성할 때는 항상 `{시작_번호}`를 마지막 번호 + 1로
  지정한다.
